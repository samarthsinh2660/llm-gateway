### Load-bearing decisions (rationale not visible in the diff)

- **`Choice.FinishReason` is `*string` with no `omitempty`** (`providers/types.go`) — deliberately a pointer so intermediate streaming chunks serialize `"finish_reason": null` per OpenAI's streaming contract, not omit the field. nil = intermediate, populated = terminal. Do not "simplify" it back to `string`; the null is the point (there's a wire-shape test in `streaming_test.go`).
- **The gateway returns HTTP 405 for a method mismatch with error type `invalid_request_error`** (`providers.HandleMethodNotAllowed`), even though `StatusCodeForError` maps that type to 400. This is intentional and matches OpenAI's own contract (OpenAI pairs `invalid_request_error` with 405 for method mismatches). A terminus-canon boundary note records this so review won't flag it; don't "correct" the status to 400.
- **Error-envelope detection in streams is centralized** — `providers.parseStreamChunk` probes for an `{"error": ...}` envelope before decoding a chunk, so a mid-stream upstream error surfaces as `StreamEvent{Err}` instead of an all-zero chunk. Both the OpenAI and local readers route through it; the Anthropic reader has its own `case "error":`. All three converge on the handler writing an OpenAI-shaped SSE error then closing.
- **`isNetworkError` excludes `context.Canceled`** (`providers/multiLocal.go`) — a cancelled request context arrives wrapped in a `net.Error`, so without the guard a client disconnect would wastefully fail over. `context.DeadlineExceeded` is deliberately NOT excluded (a per-endpoint dial timeout should still fail over). EOF/ErrUnexpectedEOF are treated as failures (dropped connection).

### Cross-file couplings

- **Secret/URL env expansion has one owner**: `Config.expandEnv` at load. Every downstream gate (`initProviders`, `collectAgoraTunnels`, `capabilityExtras`, `validateProviders`) reads already-expanded values — do not re-add scattered `os.ExpandEnv` calls. A written-non-empty value that resolves empty is a boot error; empty stays "not configured". Agora has the symmetric rule in `agora.ResolveConfig`/`expandStrings`.
- **`collectAgoraTunnels` still mirrors `initProviders`' init gates exactly** (unchanged invariant, now guarded by a canon quality). Tunnel names are trimmed once in `Config.normalize` so both sides agree.
